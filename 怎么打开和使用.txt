速映 FlashPlay —— 怎么打开、怎么用
========================================

【怎么打开】
  双击  速映.exe          ← 就是这个，不用装 Python、不用装播放器
  （图标是紫色的闪电播放标；如果 Windows 提示"未知发布者"，点"更多信息 → 仍要运行"）

【文件夹里都是什么】
  速映.exe         主程序（双击打开）
  yt-dlp.exe        下载内核（首次使用时自动获取；也可以自己放一个）
  player\mpv.exe    内置播放内核（播放功能用它，别删；没有它会自动重新下载）
  tools\ffmpeg\     合并内核（下载高清视频时自动获取，别删）
  tools\aria2\      磁力内核（首次磁力下载时自动获取）
  sy.py             源代码（想改代码或发布到 GitHub 用这个）
  downloads\        下载的视频都放这里
  README.md         项目说明
  docs\screenshot.png  界面截图

【完整流程：下载 → 直接播放】
  1. 把视频链接粘贴到底部输入框（回车 = 加入队列）
  2. 右侧选画质（最佳 / 1080P / 720P / 480P / 仅音频 MP3）
  3. 等任务变成"已完成"
  4. 双击那一行任务（或选中后点右侧「▶ 播放」）
     → 窗口切成播放视图，视频直接在应用里播放
  5. 播放控制：播放/暂停（空格）、停止、进度条拖动跳转、
     时间显示、倍速 1.0x~2.0x、全屏（F11）、音量
  6. 点「← 返回任务列表」回到下载界面

  忘了按钮是干什么的？把鼠标停在按钮上 0.3 秒，会弹出小气泡告诉你是谁：
  比如悬停"试看"→"不下载，直接在内置播放器里在线播放"。
  工具栏图标、输入框、下拉框、进度条、任务列表都有说明。

  没下载也想看？点「试看」，边下边播（流式播放，不能拖动进度）。

【两种下载方式】
  底部有个下拉框，可以选「网址下载」或「磁力下载」；粘贴 magnet: 链接会自动切换。

  · 网址下载：B站/YouTube 等 1800+ 网站的视频页面链接（用 yt-dlp）
  · 磁力下载：magnet:?xt=urn:btih:… 磁力链接（BitTorrent，P2P，用 aria2c）
      - 第一次使用会提示自动下载 BT 内核 aria2c（约 2.4MB，国内镜像加速）
      - 支持断点续传（中断后重新下载会接着传），下载完成即停止，不做种（不对外上传）
      - 磁力任务没有"画质"选项（内容由种子决定），也没有封面/UP主这些网站信息

  提醒：磁力下载请只用于你**有权下载**的内容（如 Linux 发行版、公共领域作品、
  你自己的文件）。用磁力做种分发受版权保护的付费内容，在多数国家属于侵权行为。

【常见问题】
  · 只能下到前几分钟？提示"试看/充电专属/大会员专享"？
    这类视频 B 站只给未付费账号发放"试看片段"（比如 3 小时全长的视频，
    匿名下载就只能拿到前 15 分钟）。这不是工具的问题，也不是工具能"破解"的。
    想下完整版，需要提供【已购买/已充电/已开大会员】的账号登录状态：
      1) 浏览器登录 B 站（账号本身要有该视频的观看权限）
      2) 用扩展「Get cookies.txt LOCALLY」导出 cookies.txt，放到本文件夹
      3) 程序里「设置 → cookies.txt 文件」选中它，再重新下载
    注意：Chrome/Edge 新版给 cookie 加了加密，直接读浏览器常失败，
    所以推荐导出成 cookies.txt 的方式（最稳）。
  · 第一次播放时如果提示没有播放内核，点"是"会自动下载（约 32MB，国内镜像加速），
    下完再点一次「播放」即可；也可以手动把 mpv.exe 放到 player\ 目录。
  · 还没有 yt-dlp？第一次下载时会自动获取（约 18MB，国内镜像加速）；
    也可以自己下载 yt-dlp.exe 放进本文件夹。
  · 下载高清时如果缺 ffmpeg：不用管——程序会自动下载合并内核（约 30MB，
    国内镜像加速，只下这一次）；也可以在「设置 → 获取 ffmpeg」手动下载。
  · 某些网站突然下不了 / 报错？多半是下载内核旧了：点「设置 → 内核维护 →
    检查 yt-dlp 更新…」，一键更新到最新版（yt-dlp 每周更新多次，建议定期点一下）。
    更新后旧版会备份为 yt-dlp.exe.bak，有问题随时还原。
  · B 站免登录一般到 480P；要 1080P 及以上，在「设置」里选 Cookies 浏览器
    （先在浏览器登录 B 站）。
  · YouTube 需要能上外网，可在「设置」里填代理，如 http://127.0.0.1:7890。
